## Functions

Although the word function has taken on a broader meaning in recent years, a function in code is a way of representing multiple lines of code with one name, 
allowing that code to be executed multiple different times or in multiple different ways while only having to type the whole code out once. In this assignment I
was tasked to use functions to play my name in morse code through a small motor that vibrates, and switch to playing SOS when a button was pressed. For the future, 
I would structure the functions that had the code for my name or sos as steps of a loop. The loop sets step to 1, 2, 3, etc. and then for each numbered step, a
letter is played. I didn't start with this idea, but I ended up using it because it allowed me to check at the end of each step if the button was pressed or unpressed, 
which I couldn't do otherwise. Then, all I had to do was check if the button was being pressed while I was playing a letter within the step, and from there I could 
use return to exit that set of dots and dashes and move directly to the next step, which includes a check for the button. This allowed me to return out of the name
function, and then play the sos function, which is structured the same way.
